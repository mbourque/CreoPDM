creopdm-agent tray

Creo.JS is linked, but the local agent on this PC is not running. Open, Checkout download, Add from disk, and the local workspace need creopdm-agent-tray on this Windows Creo PC.

1. Start it (if you already have it)

  1. Find creopdm-agent-tray.exe where you installed it (or the Start menu / taskbar if you pinned it).
  2. Run it — a tray icon appears near the clock (no console window).
  3. Return to CreoPDM and refresh; the top-bar pill should become Creo: Connected.

Quick check: open http://127.0.0.1:8766/health in a browser on this PC — it should respond when the tray is up.

2. Download (if you do not have it yet)

Download creopdm-agent-tray.exe

Save it somewhere stable (for example %LOCALAPPDATA%\CreoPDM-agent\), then double-click to start.

{% endif %}

3. Start automatically when you sign in to Windows

So you do not have to launch the tray every morning:

  1. Press Win+R, type shell:startup, press Enter — that opens your personal Startup folder.
  2. Right-click creopdm-agent-tray.exe → Create shortcut, and move that shortcut into the Startup folder (or copy the .exe itself there if you prefer).
  3. Sign out and back in once to confirm the tray icon appears without opening it by hand.

Keep the real .exe in a fixed folder; only put a shortcut in Startup if you move the file later. You can also pin the tray to the taskbar for a one-click start when it is not set to autostart.

The agent is separate from the CreoPDM server. It must run on the Windows PC that runs Creo.
