creopdm-agent tray

A small Windows app that runs in the system tray on your Creo PC. CreoPDM on the server holds the vault; the tray downloads and uploads CAD on this machine so Open, Checkout, Add, and the local workspace work.

How new users get here

  1. Sign in to CreoPDM in Creo’s built-in browser (Embedded open mode).
  2. When Creo.JS is linked but the tray is not running, the top-bar pill shows Creo: Agent offline (yellow).
  3. Click that pill — it opens this page (same named tab as Help).

You can also open /help/agent-tray anytime while signed in. In Chrome/Edge the pill usually says Creo: Session offline instead — use Creo’s browser for Embedded work.

1. Start it (if you already have it)

  1. Find creopdm-agent-tray.exe where you saved it (or a taskbar / Startup shortcut).
  2. Double-click it — a tray icon appears near the clock (no console window). Look in the overflow (^) if you do not see it.
  3. Return to CreoPDM and soft-refresh or wait a moment; the pill should become Creo: Connected.

Quick check on this PC: open http://127.0.0.1:8766/health in any browser — it should respond when the tray is up.

2. Download (if you do not have it yet)

3. Start automatically when you sign in to Windows

So you do not have to launch the tray every morning:

  1. Press Win+R, type shell:startup, press Enter — that opens your personal Startup folder.
  2. Right-click creopdm-agent-tray.exe → Create shortcut, and move that shortcut into the Startup folder.
  3. Sign out and back in once to confirm the tray icon appears without opening it by hand.

Keep the real .exe in a fixed folder; put only a shortcut in Startup. You can also pin the tray to the taskbar for a one-click start.

Using the tray day to day

Right-click the tray icon:

  • Show status — port, version, and local cache folder
  • Show logs — live log window (also written under %LOCALAPPDATA%\CreoPDM-agent\logs\agent.log)
  • Open cache folder — Explorer on the local product workspaces (default %LOCALAPPDATA%\CreoPDM-agent\workspaces)
  • Quit — stop the agent (CreoPDM will show Agent offline again until you restart it)

With the tray running and CreoPDM open in Creo’s browser:

  • Open / Checkout — files download into the local workspace, then Creo opens them
  • Add — pick folders/files on this PC via the agent
  • Open workspace — opens that product’s local folder in Explorer
  • Check In — syncs local Creo saves back toward the vault

If something fails

  • Pill still Agent offline — confirm the tray icon is present; open http://127.0.0.1:8766/health; try Quit then start the exe again.
  • Pill says Session offline — you are not in Creo’s embedded browser (or Creo.JS has not linked). Open CreoPDM from Creo, not only Chrome/Edge.
  • Open / Add errors mention the agent — start the tray, then retry.
  • Download button missing or 404 — ask an admin to publish the exe on the server (README).

The agent is separate from the CreoPDM server. It must run on the Windows PC that runs Creo.
