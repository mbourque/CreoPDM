Uses the running Creo session only inside Creo’s embedded browser. Anywhere else (or if Creo.JS is offline), Open uses the OS file association via creopdm-agent (or a browser download if the agent is offline)—same as double-clicking the file. Covers Creo-openable models (parts, assemblies, drawings, STEP, …). Inside Creo, Embedded Open drives File > Open to the local workspace folder and sets Creo’s working directory there by default (same as the Open dialog checkbox) — including Multi-CAD (SolidWorks, CATIA, Inventor, …). Images, PDFs, and other non-Creo files always use the OS association.
