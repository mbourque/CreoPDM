Extensions that use Creo-style .ext.N versioning. Add (files or folder) skips older numbered saves and uploads only the latest. Purge workspace uses the same list for local workspace cleanup: it deletes saves older than the vault copy; the vault revision and any newer local work stay. The vault is not changed.

Comma-separated, with or without the dot. Default: {{ settings.default_purgeable_extensions | join(', ') }}
