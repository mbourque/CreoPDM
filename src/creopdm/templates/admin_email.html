SMTP setup help

Local Postfix (typical Linux install)

  • Set SMTP server to localhost and port 25.
  • Leave TLS and authentication unchecked — local connections usually need no login.
  • CreoPDM talks to Postfix (or Exim/sendmail) on the CreoPDM server, not on the user’s PC.
  • Set a From address that your MTA accepts for local send (often the server hostname domain).

External / authenticated SMTP

  • Use your provider’s SMTP host (for example smtp.example.com).
  • Port 587 with Use TLS (STARTTLS) is the usual choice. Some providers use 465 (implicit TLS) — prefer 587 with STARTTLS here.
  • Turn on Use SMTP authentication and enter the mailbox username and password (or app password).
  • Allow outbound TCP 587 (or 465) from the CreoPDM host through any firewall.
  • The From address should be a mailbox your provider allows; align SPF/DMARC for that domain when sending to the internet.

After saving, use Send test email before relying on alerts.
