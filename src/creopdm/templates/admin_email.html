Local Postfix

CreoPDM sends through 127.0.0.1:25 on the CreoPDM server (same idea as mail / Postfix). No username or password. Use a From address your MTA accepts for local send (often the server hostname domain). Save, then use Send test email.

Authenticated SMTP

Leave password blank to keep the current value. Typical provider setup: port 587, TLS on, authentication on (Gmail needs an App password). Allow outbound TCP 587 from this host. From address must be allowed by the provider.

Test email

Uses saved settings only. Defaults to the administrator email when left blank. Save your changes before sending a test.
