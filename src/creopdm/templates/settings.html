System Settings

These options apply to this CreoPDM server. They are not stored in product Git history.

Availability

When CreoPDM is unavailable, people who are not administrators see a message instead of the usual pages (on their next page open or navigation). Administrators can still use the app and these settings. This is display-only: it does not cancel uploads, check-ins, or other work already in progress.

Shown to non-administrators while unavailable. Default: {{ settings.default_site_unavailable_message }}

Open Creo models with

Uses the running Creo session only inside Creo’s embedded browser. Anywhere else (or if Creo.JS is offline), Open uses the OS file association via creopdm-agent (or a browser download if the agent is offline)—same as double-clicking the file. Covers Creo-openable models (parts, assemblies, drawings, STEP, …). Multi-CAD (SolidWorks, CATIA, Inventor, …) goes to the agent cache; CreoPDM drives File > Open to that folder without changing Creo’s working directory. Images, PDFs, and other non-Creo files always use the OS association.

Optional override. CreoPDM ships a bundled creojs.js. Set a path only if you need a different Creo.JS build from your install.{% if settings.creo_js_library_resolved %} Serving: {{ settings.creo_js_library_resolved }}.{% endif %}

Vault

Master repository for each product (Git history and vault copies), one folder per product. On Linux the default is ~/.local/share/CreoPDM/vaults. Point this at the vault folder, not ~/.local/share/CreoPDM itself (that is the application data directory). Creo working files on the client PC live in the local agent workspace, not in this vault.

Default: {{ settings.default_workspace_root }}

Creo Models

Extensions counted and filtered by the Creo Models chip. The Other chip is everything else on the file list. Numbered saves such as shaft.prt.3 count as .prt.

Comma-separated, with or without the dot. Default: {{ settings.default_cad_models_extensions | join(', ') }}

Documents

Extensions counted and filtered by the Documents chip.

Comma-separated, with or without the dot.

Creo-openable models

Types Creo can open. Click-to-open uses Creo for these files. Numbered saves such as shaft.prt.3 and outline.dxf.4 count as those extensions.

Comma-separated, with or without the dot.

Text files

CAD-like files that open with the Windows text editor, not Creo. They still count as CAD in the product.

Comma-separated, with or without the dot.

Non openable CAD data

CAD-like files Creo does not open. They still count as CAD in the product but will not open.

Comma-separated, with or without the dot.

Numbered saves

Extensions that use Creo-style .ext.N versioning. Add (files or folder) skips older numbered saves and uploads only the latest. Purge workspace uses the same list for local agent-cache cleanup: it deletes saves older than the vault copy; the vault revision and any newer local work stay. The vault is not changed.

Comma-separated, with or without the dot. Default: {{ settings.default_purgeable_extensions | join(', ') }}

File type names

Optional labels for the Type column. Use an extension such as .stp, .step, or a file name such as reviewref.inf. If a row is empty or missing, CreoPDM uses the usual names such as Creo Part or Pdf.

Edit type names

Ignored files

These never enter the vault, are never stored in Git, and never appear in the file list. Patterns are written to each product's .gitignore.

Comma-separated gitignore patterns.

Network

TCP port for this PC and phones on the LAN. 0 picks a free port each start. A specific port such as 8765 stays the same until it is already in use. Takes effect the next time CreoPDM starts.

0 = automatic. The agent tray calls this CreoPDM server over HTTP — CreoPDM does not open a special inbound port for the tray.

Local Creo agent

When this page runs inside Creo’s browser, open/materialize uses the local creopdm-agent workspace on the Creo PC. Change this if the agent listen port is not 8766. File list refresh controls how often the page checks the vault for pending saves and new files.

500–120000 ms. Default 5000 (5 seconds). Reload the product page after saving. This also drives how often the page asks the local agent for new workspace files.

0–1440. Default 10. After this many minutes with no mouse, keyboard, or touch activity, file-list polling stops until you interact again. 0 = never pause for idle (hidden tabs still pause). Reload the product page after saving.

Database

Leave blank to use the local SQLite file. Postgres takes effect on the next CreoPDM start. You can type @ in the password (saved readable; encoded automatically when connecting).

Example: postgresql+psycopg://creopdm:PASSWORD@localhost:5432/CreoPDM — Default SQLite: {{ settings.default_database_url }}
