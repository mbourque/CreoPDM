Settings

These options apply to this workstation. They are not stored in project Git history.

Open Creo models with

This setting applies to models Creo.JS can open in-session (parts, assemblies, drawings, STEP, …). SolidWorks, CATIA, Inventor, and similar Multi-CAD files are fetched into the local agent cache; CreoPDM drives File > Open in the running session and navigates that dialog to the cache folder (your Creo working directory is not changed). Images, PDFs, and other non-Creo files use the Windows association.

Optional override. CreoPDM ships a bundled creojs.js for Embedded mode. Set a path only if you need a different Creo.JS build from your install.{% if settings.creo_js_library_resolved %} Serving: {{ settings.creo_js_library_resolved }}.{% endif %}

Vault

Master repository for each project (Git history and vault copies), one folder per project. On Linux the default is ~/.local/share/CreoPDM/vaults. Point this at the vault folder, not ~/.local/share/CreoPDM itself (that is the application data directory). Creo working files on the client PC live in the local agent workspace, not in this vault.

Default: {{ settings.default_workspace_root }}

Creo Models

Extensions counted and filtered by the Creo Models chip. The Other chip is everything else on the file list. Numbered saves such as shaft.prt.3 count as .prt.

Comma-separated, with or without the dot. Default: {{ settings.default_cad_models_extensions | join(', ') }}

Documents

Extensions counted and filtered by the Documents chip.

Comma-separated, with or without the dot.

Creo-openable models

Types Creo can open. Click-to-open uses Creo for these files. Numbered saves such as shaft.prt.3 and outline.dxf.4 count as those extensions.

Comma-separated, with or without the dot.

Text files

CAD-like files that open with the Windows text editor, not Creo. They still count as CAD in the project.

Comma-separated, with or without the dot.

Non openable CAD data

CAD-like files Creo does not open. They still count as CAD in the project but will not open.

Comma-separated, with or without the dot.

File type names

Optional labels for the Type column. Use an extension such as .stp, .step, or a file name such as reviewref.inf. If a row is empty or missing, CreoPDM uses the usual names such as Creo Part or Pdf.

Edit type names

Ignored files

These never enter the vault, are never stored in Git, and never appear in the file list. Patterns are written to each project's .gitignore.

Comma-separated gitignore patterns.

Network

TCP port for this PC and phones on the LAN. 0 picks a free port each start. A specific port such as 8765 stays the same until it is already in use. Takes effect the next time CreoPDM starts.

0 = automatic. The agent tray calls this CreoPDM server over HTTP — CreoPDM does not open a special inbound port for the tray.

Local Creo agent

When this page runs inside Creo’s browser, open/materialize uses the local creopdm-agent workspace on the Creo PC. Change this if the agent listen port is not 8766. File list refresh controls how often the page checks the vault for pending saves and new files.

500–120000 ms. Default 2000. Reload the project page after saving.

Database

Leave blank to use the local SQLite file. A Postgres URL is for a later Linux/server move and takes effect the next time CreoPDM starts.

Default SQLite: {{ settings.default_database_url }}
