Settings

These options apply to this workstation. They are not stored in project Git history.

Open Creo models with

Word, Excel, PDF, text, and other non-CAD files always open with their Windows association.

Workspace

Checked-out and downloaded files are copied here, one folder per project, with every file in that folder. The default is shown; choose another folder if you want a different workspace.

Default: {{ settings.default_workspace_root }}

Creo Models

Extensions counted and filtered by the Creo Models chip. The Other chip is everything else on the file list. Numbered saves such as shaft.prt.3 count as .prt.

Comma-separated, with or without the dot. Default: {{ settings.default_cad_models_extensions | join(', ') }}

Documents

Extensions counted and filtered by the Documents chip.

Comma-separated, with or without the dot.

Creo-openable models

Types Creo can open. Click-to-open uses Creo for these files. Numbered saves such as shaft.prt.3 and outline.dxf.4 count as those extensions.

Comma-separated, with or without the dot.

Text files

CAD-like files that open with the Windows text editor, not Creo. They still count as CAD in the project.

Comma-separated, with or without the dot.

Non openable CAD data

CAD-like files Creo does not open. They still count as CAD in the project but will not open.

Comma-separated, with or without the dot.

File type names

Optional labels for the Type column. Use an extension such as .stp, .step, or a file name such as reviewref.inf. If a row is empty or missing, CreoPDM uses the usual names such as Creo Part or Pdf.

Edit type names

Ignored files

These never enter the workspace, are never stored in Git, and never appear in the file list. Patterns are written to each project's .gitignore.

Comma-separated gitignore patterns.

Network

TCP port for this PC and phones on the LAN. 0 picks a free port each start. A specific port such as 8765 stays the same until it is already in use. Takes effect the next time CreoPDM starts.

0 = automatic.

Database

Leave blank to use the local SQLite file. A Postgres URL is for a later Linux/server move and takes effect the next time CreoPDM starts.

Default SQLite: {{ settings.default_database_url }}
